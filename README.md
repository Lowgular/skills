# skill-grader-examples

Agent Skills, each with the evals that show it works.

| skill | what it does |
|---|---|
| [figma-skills](figma-skills/) | **figma-browser** — read a Figma design (values, tokens, variants, component properties, styles) through the Figma Plugin API in your own logged-in Chrome. Read-only. |

More to come.

Each directory is self-contained: the skill itself, the graders that score it,
and a starter `eval.yaml` you can run. Start with the README inside the one you
want.
